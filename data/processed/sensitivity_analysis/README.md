# Sensitivity Analysis

This directory contains supplementary statistical
outputs from the MIS581 housing-market capstone.

The analysis compares reduced-predictor regression
models using 119 and 133 MSA-year observations.

Removing real household-income growth allowed
additional observations from 2005 and 2021 to be
included. The 2020 observations remained excluded
because ACS population data were unavailable.

The sensitivity analysis evaluates how changes in
sample coverage influence estimated regression
coefficients and statistical significance.

These files represent historical analytical outputs
and should be interpreted alongside the final
capstone paper and regression-model limitations.
