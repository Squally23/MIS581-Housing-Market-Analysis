# Processed Annual Datasets

This directory contains the standardized CSV inputs used
in the MIS581 capstone's PostgreSQL warehouse workflow.

All files represent the 2005–2024 analysis period.
The datasets were prepared using Python and aligned
to annual reporting periods.

The main metropolitan datasets are organized by
five-digit CBSA identifier and calendar year.

See the parent directory's README.md for source
attribution, expected record counts, and limitations.

These files are historical analytical snapshots,
not current agency releases.
