# PostgreSQL Scripts

This directory contains the SQL scripts used to develop,
populate, and validate the MIS581 capstone data warehouse.

The project uses three PostgreSQL schemas:

- staging: Imported and standardized source datasets.
- warehouse: Metropolitan dimensions and annual fact tables.
- analytics: Integrated analytical views and Tableau reporting.

The finalized scripts will include database structures,
data transformations, reconciliation checks, and the
Tableau reporting view.

SQL scripts will be reviewed before publication to remove
credentials and machine-specific information.
