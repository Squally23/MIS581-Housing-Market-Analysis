# Project Documentation

This directory contains supporting documentation for
the MIS581 housing-market analysis capstone.

Planned contents include:

- Research objectives, questions, and hypotheses
- Data sources and integration methodology
- PostgreSQL warehouse architecture
- Python analytical workflow
- Data-quality and validation procedures
- Statistical model specifications and limitations
- Tableau dashboard design and functionality
- Reproducibility and execution instructions

Documentation will distinguish completed analytical
procedures from proposed extensions or future research.

The project examines historical associations between
economic indicators and housing-price changes across
seven U.S. metropolitan areas from 2005 to 2024.

Results should not be interpreted as causal estimates
or validated housing-price forecasts.
