# Python Scripts

This directory contains the finalized Python scripts
supporting the MIS581 housing-market analysis.

The project uses Python for:

- Source-data exploration and preparation
- Data cleaning and annual standardization
- Validation and data-quality checks
- Integration with PostgreSQL
- Statistical modeling and diagnostics
- Sensitivity analysis and visualization

Finalized scripts will be reviewed for reproducibility,
documented dependencies, and removal of sensitive
connection information before publication.
